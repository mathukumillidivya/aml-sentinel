# Data in this repository

## Source

IBM Transactions for Anti Money Laundering (AML), by Erik Altman and colleagues
(IBM), described in "Realistic Synthetic Financial Transactions for Anti-Money
Laundering Models", NeurIPS 2023 Datasets and Benchmarks. Published on Kaggle at
https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml
under the Community Data License Agreement - Sharing - Version 1.0 (CDLA-Sharing-1.0).

The data is synthetic. It contains no real accounts, customers, or transactions.

## Files derived from it

These files are derived from the IBM dataset and are shared under the same
licence, CDLA-Sharing-1.0:

| Location | What it is |
|---|---|
| `data/ibm_sample/` | The first 2,000 rows, 500 laundering rows, and 120 lines of the patterns file, used to build the converter |
| `results/ibm/` | Alerts, scores, features, and agent runs computed from HI-Small and LI-Small |
| `app/review.html` | The review screen, which embeds 300 alerts and the accounts connected to them |
| branches `ibm-cache`, `ibm-cache-LI-Small` | The converted transaction tables the pipeline loads |

The raw dataset is not stored here. `src/ibm_prepare.py` rebuilds the converted
tables from a Kaggle download.

## Synthetic sample written for this project

`data/transactions.csv.gz` and `data/accounts.csv` are generated by
`src/generate_data.py` and are covered by the repository's MIT licence.
